# Rock Paper Scissors 

A simple and interactive **Rock Paper Scissors game** built using HTML, CSS, and JavaScript. Play against the computer, see the result of every round, and keep track of your wins, losses, and ties.

## Features

- **Three Move Buttons:** Choose Rock, Paper, or Scissors to play against the computer.
- **Instant Results:** Displays whether the player won, lost, or tied after every move.
- **Score Counter:** Tracks the total number of wins, losses, and ties.
- **Reset Counter:** Resets all scores to zero so you can start a new game.
- **Interactive UI:** Simple and easy-to-use interface.

## Technologies Used

- **HTML5** — Structures the game interface.
- **JavaScript** — Implements game logic, generates the computer's move, determines the winner, and updates the score.

## How to Play

1. Open the game in your browser.
2. Click **Rock**, **Paper**, or **Scissors** to make your move.
3. The computer randomly selects its move.
4. The game displays the result of the round:
   - **Win:** The player wins the round.
   - **Loss:** The computer wins the round.
   - **Tie:** Both choose the same move.
5. Check the score counter to track your performance.
6. Click **Reset Counter** to reset wins, losses, and ties to zero.

## Game Rules

- Rock beats Scissors.
- Scissors beats Paper.
- Paper beats Rock.
- Choosing the same move as the computer results in a tie.

## How to Run

1. Clone this repository:

   ```bash
   git clone <https://github.com/shashzone/Rock-Paper-Scissor.git>
   ```

2. Navigate to the project directory:

   ```bash
   cd <Rock Paper Scissor>
   ```

3. Open `rock paper scissor game.html` in your web browser.

No additional installations or dependencies are required.
